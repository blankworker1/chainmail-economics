# Chainmail Economics: version 1 checklist

A run sheet for one test session of version 1. The session is one game: build the cloth, receive the gift, set up wallets, trade in one market, and debrief.

**Status: draft.** The wallet steps in phase 3 are not yet confirmed against the current Blitz Wallet app. They are marked *unconfirmed*. The game has not yet been run with a real class.

The game is designed to run at a slow pace. The tip to give the class is: **always think before you act.**

## Before the day

### Blitz Wallet tests

- [ ] Send a test payment between two phones with a trade line as the message.
- [ ] Check that the wallet history on both phones shows the amount, the time, and the message.
- [ ] Check whether the message is typed by the buyer or set by the seller's payment request.
- [ ] Claim a 600 sats gift code on a phone with a fresh install.
- [ ] Check the eight wallet slides in the game against the current app screens.

### Gift codes

- [ ] Create one Blitz Wallet gift code of 600 sats for each participant, and a few spares.
- [ ] Print each code on its own card, or prepare to hand each one over privately.
- [ ] Keep the codes out of sight. Each code is cash, and anyone who scans it can take the gift.

### The pages

- [ ] Open the landing page from its web address, not from a file. The QR code and the WhatsApp buttons only work from a web address.
- [ ] Open the card page on at least two different phones and check the sliders, the send button, and the trading screen.
- [ ] If cards and trade lines should arrive by WhatsApp, enter the facilitator's number on the landing page.

### Decisions

- [ ] Trading time for the market: 15 minutes.
- [ ] Shocks: off, by hand, or on the automatic timer.
- [ ] Board size. The default is 11 by 11.

### To bring

- [ ] One spring-gate clip ring for each participant.
- [ ] Dice. One between a few participants is enough.
- [ ] The gift code cards.
- [ ] A large screen for the board, with sound for the bell.
- [ ] Paper and pens, for recovery words.

## In the room, before the class arrives

- [ ] Check the internet connection. Wallet setup and payments need it.
- [ ] Open the landing page on the large screen, then open the game from it.
- [ ] Press **Start a new game** if an old game is showing.
- [ ] Set the board size and the shock setting.
- [ ] Test the sound. The bell must be heard across the room.
- [ ] Show the QR code for the card page on the screen.

## Phase 1: Build the cloth

Start time: ______

- [ ] Give each participant a ring.
- [ ] Say: "Always think before you act."
- [ ] Each participant scans the QR code and opens the card on their phone.
- [ ] **Roll.** Each participant rolls a dice four times: energy, food, land, skills.
- [ ] **Set.** They choose a username and set each slider to the number rolled. Money cannot be set.
- [ ] **Send.** They show, say, or send their five-digit number. Enter each one in the game.
- [ ] The first link goes to the centre of the board.
- [ ] Each later link picks a dashed place. Each neighbour accepts or denies. One acceptance is enough.
- [ ] After three refusals, a link waits until the next round. Press **Start next round** when the queue needs another turn.
- [ ] Continue until everyone has had the chance to join.

End time: ______

## Phase 2: The gift

- [ ] Say: "Nobody has any money. The game gifts everyone 6 units of money."
- [ ] Press **Gift money to everyone**. Every link now shows 600 sats.

## Phase 3: Wallet setup

Start time: ______

These steps follow the slides in the game. *Unconfirmed until the Blitz tests are done.*

- [ ] Hand each participant their gift code card, privately.
- [ ] Press **Lightning wallet**. The slides open full screen.
- [ ] Slide 1: the game has given you money.
- [ ] Slide 2: find your gift code, and keep it to yourself.
- [ ] Slide 3: scan the code with the phone's camera. *Unconfirmed.*
- [ ] Slide 4: install Blitz Wallet and open it. *Unconfirmed.*
- [ ] Slide 5: accept the gift. 600 sats arrive. *Unconfirmed.*
- [ ] Slide 6: write down the recovery words and keep them private.
- [ ] Slide 7: to be paid, show the receive code. To pay, scan, enter the amount, and add the trade line as the message. *Unconfirmed.*
- [ ] Slide 8: start trading.
- [ ] Check that every participant's wallet shows 600 sats before moving on.
- [ ] Each participant presses **Open trading** on their card page and enters their place on the board.

End time: ______

## Phase 4: Trade

Start time: ______

- [ ] Explain the aim: reach enough, which is 3 or more in energy, food, land, and skills. The class aim is for as many links as possible to get there.
- [ ] Explain the rules: one unit at a time, the buyer asks, one purchase each, and only between bonded neighbours in this first market.
- [ ] Run two trades on the board with **Trade a unit**, one at a time, so the class sees how it works.
- [ ] Explain the order for the buyer: record the purchase, pay with the trade line as the message, then send the same line to the facilitator.
- [ ] Explain that the seller records the sale on their own screen once the sats arrive.
- [ ] Set the trading time to 15 minutes and ring the opening bell.
- [ ] Let the class trade. Collect trade lines as they arrive.
- [ ] The closing bell rings at zero. It ends the active part of the game.
- [ ] Paste or type the trade lines into the box and press **Enter trades**. Lines that fail stay in the box with a reason.
- [ ] Settle any failed line against the wallet history. The wallet is the ledger.

End time: ______

## Phase 5: Debrief

- [ ] Leave the board on the screen.
- [ ] Press **Save to file** to keep the board, the trades, and the prices.
- [ ] Ask: who kept their sats, and why?
- [ ] Ask: did prices stay at 100 sats? Which attribute cost most?
- [ ] Ask: did the class end with one cloth or several, and is that healthy?
- [ ] Ask: who gave something away?
- [ ] Remind participants that the wallet and the sats are theirs to keep, and so are the recovery words.
